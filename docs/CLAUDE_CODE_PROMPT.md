# Claude Code 一鍵複製開發提示

你可以把下方提示整段貼到 Claude Code。日後你有新想法時，也可以先丟給 Manus AI，我會幫你整理成類似格式。

```text
你現在接手一個 Python 台股 AI 選股與 Telegram 推播專案。請先閱讀 README.md、src/brain.py、src/data_sources.py、src/indicators.py、src/main.py 與 .github/workflows/tw-stock-bot.yml。

專案目標是：
1. 使用免費公開資料源，優先使用 TWSE/TPEX 官方 OpenAPI。
2. 建立可解釋的多因子選股大腦，包含技術面、量能、籌碼面、基本面、新聞事件與風控。
3. 透過 GitHub Actions 自動執行早報、盤中提醒與晚報。
4. 透過 Telegram Bot 推播結果。
5. 保持程式穩定，不要高頻請求，不要把 Token 寫進程式碼。

請你在不破壞既有架構的前提下完成以下任務：

【我要新增的策略想法】
請把這一段換成我的新想法，例如：外資連買 3 天、爆量突破 20 日均線、月營收年增率大於 20%、排除本益比超過 60 倍。

【修改要求】
1. 如果需要新指標，請修改 src/indicators.py。
2. 如果需要新分數或新過濾條件，請修改 src/brain.py。
3. 如果需要新資料源，請修改 src/data_sources.py，並加入快取、重試與欄位容錯。
4. 如果需要新推播格式，請修改 src/brain.py 的 format_candidates。
5. 請保留 Telegram Secrets 的用法，不要要求我把 Token 寫死在程式。
6. 請在 README.md 補上策略說明與風險提醒。
7. 請最後列出你修改了哪些檔案，以及如何測試。
```

## 建議的日後策略描述格式

為了讓 AI 更容易把你的概念寫成程式，請盡量用以下格式描述。

| 欄位 | 範例 |
|---|---|
| 選股目的 | 找盤中可能噴出的強勢股 |
| 技術條件 | 收盤價或盤中價格突破 20 日均線 |
| 量能條件 | 今日量大於 20 日均量 2 倍 |
| 籌碼條件 | 外資連買 3 天，融資不要暴增 |
| 基本面條件 | 月營收年增率大於 20% |
| 排除條件 | 股價低於 10 元、成交金額低於 3000 萬、本益比大於 60 |
| 推播條件 | 總分大於 75 且同一檔 60 分鐘內不重複推播 |
```
